# Финальное видео

Последняя сцена игры происходит в **реальном мире**, и играют в ней живые актёры:
Тимур, Алина и Егор.

- **Сценарий для съёмки:** [`final_cutscene.txt`](final_cutscene.txt) — роли, сцены, реплики, советы.
- **Куда класть ролик:** в эту папку под именем **`finale.mp4`** (подойдут также `.mov`, `.mkv`, `.webm`, `.avi`).
  После последнего уровня игра откроет его в обычном видеоплеере — она «выходит в реальность» из своего окна.
- **Пока ролика нет**, игра показывает ту же сцену текстом (секция `[epilogue]` в [`../story.txt`](../story.txt)).
  Если меняете сценарий — поправьте и её, чтобы текст и видео рассказывали одно и то же.

## Требования к файлу

- MP4 (H.264 + AAC) — открывается везде без кодеков.
- 1280×720 или 1920×1080, 30 кадров/с, 1,5–2 минуты.
- **Меньше 50 МБ** — GitHub не принимает файлы больше 100 МБ. Сжать можно так:

```bash
ffmpeg -i raw.mp4 -vf scale=1280:-2 -c:v libx264 -crf 26 -preset slow -c:a aac -b:a 128k finale.mp4
```
