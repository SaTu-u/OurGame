# Финальное видео

Положите сюда ролик с именем **`finale.mp4`** — в конце игры он откроется в обычном видеоплеере
(игра «выходит в реальность» из своего окна). Подходят также `finale.mov`, `.mkv`, `.webm`, `.avi`.
Пока файла нет, игра показывает заглушку.

## Требования к файлу

- MP4 (H.264 + AAC) — открывается везде без кодеков.
- 1280×720 или 1920×1080, 30 кадров/с.
- 1–2 минуты.
- **Меньше 50 МБ** — GitHub не принимает файлы больше 100 МБ. Сжать можно так:

```bash
ffmpeg -i raw.mp4 -vf scale=1280:-2 -c:v libx264 -crf 26 -preset slow -c:a aac -b:a 128k finale.mp4
```

## Сценарий ролика (черновик)

Герои — те же трое, что в игре: Пиксель, Глюк и Шейдер. Только теперь — люди.

1. **Белый экран.** Из белого «проявляется» комната. Тимур (Пиксель) лежит на полу и щурится,
   как будто впервые видит в нормальном разрешении. Смотрит на свои руки: «Пальцы. У меня есть ПАЛЬЦЫ».
2. **Глюк.** Второй участник появляется в кадре рывками (снимаете с паузами — эффект «лагает»).
   «Братан, мы в 4K. Тут даже текстуры не грузятся — они просто есть».
3. **Шейдер.** Третий входит с фонариком/лампой, светит всем в лицо: «Без меня тут было бы темно и грустно».
4. **Сборщик мусора.** Кто-то за кадром выносит мусорный пакет. Все трое замирают.
   Шёпотом: «Не стой на месте!» — и разбегаются в разные стороны.
5. **Финал.** Трое сидят рядом за компьютером и запускают… эту игру. На экране мигает пиксель.
   Тимур: «Слушай… а он ведь тоже когда-нибудь выйдет». Затемнение.

Снимать можно на телефон горизонтально. Музыка — без авторских прав (например, из фонотеки YouTube Audio Library).
