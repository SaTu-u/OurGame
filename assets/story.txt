# ================================================================
#  ИЗ ПИКСЕЛЯ В ЛЮДИ — сценарий игры
# ================================================================
#  Этот файл читает игра. Код пересобирать не нужно — просто правь текст.
#
#  [имя_секции]         — начало секции (имена используются в коде и в уровнях)
#  Алина: привет         — реплика персонажа (имя до двоеточия, не длиннее 24 символов)
#  > Текст               — слова рассказчика (двоеточие внутри можно)
#  # ...                 — комментарий, игра его не видит
#
#  О ЧЁМ ИСТОРИЯ
#  Тимур написал друзьям «Мне всё равно, делайте сами» и уснул. Проснулся он пикселем
#  в параллельном мире, который уничтожен: в нём всем стало всё равно, и пришло Обнуление —
#  оно стёрло цвета, потом формы, и от мира осталась одна командная строка.
#  Тимура ведут Алина и Егор этого мира — последние, кому не всё равно. Их собственный
#  Тимур когда-то сказал те же слова и исчез первым. Чем больше наш Тимур меняется,
#  тем больше мир вспоминает себя: текст → кривое 2D → красивое 2D → реальность.
#
#  ПЕРСОНАЖИ
#    Тимур         — главный герой, за него играем. В начале: «мне всё равно», «я сам», «потом».
#    Алина         — учит принимать помощь и говорить «спасибо». Даёт двойной прыжок.
#    Егор          — держит последний свет мира. Учит не тянуть и отвечать за других. Даёт рывок.
#    Другой Тимур  — Тимур параллельного мира. Встречается только в осколках памяти.
#    ???           — голос в терминале (это Алина, пока она не назвала себя).
#
#  ЧТО МЕНЯЕТСЯ В ТИМУРЕ
#    Терминал     — «потом» больше не работает: кто стоит на месте, того стирает.
#    Стрёмное 2D  — учится просить о помощи и благодарить (Алина).
#    Красивое 2D  — учится действовать сразу и помогать другим (Егор), просит прощения.
#    Реальность   — отвечает друзьям и приходит к ним сам.
# ================================================================
